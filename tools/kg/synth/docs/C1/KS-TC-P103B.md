## 1. 適用

この基準は、NA30 系列、NA50 系列及び NE60 系列の過給機について、単独試運転で計測したコンプレッサ性能を標準吸込状態へ換算するときの細目、判定の方法及び計算例を定める。

換算の共通の事項は、KS-TC-P001 による。標準吸込状態は、同基準の 4-1 による。この基準は、初号機の単独性能確認試験及び量産機の単独試運転検査の、いずれにも適用する。

タービンの性能は、この基準の対象としない。計画性能曲線は、過技性が型式ごとに定め、技術資料 TS-0520 に収める。

換算及び判定の計算は、過検の検査員が行う。初号機については、過技性が検算する。計算に表計算の書式を用いる場合は、過技性が確かめた書式に限る。書式を改めたときは、過技性が 5. の計算例と同じ値になることを確かめてから、過検に渡す。

## 2. 計測値及び記号

この基準で用いる記号は、次による。

| 記号 | 量 | 単位 |
|---|---|---|
| N | 回転速度 | min-1 |
| Q | 空気量 | m3/s |
| p0 | 大気圧力 | kPa |
| p1 | 吸込全圧 | kPa |
| p2 | 吐出全圧 | kPa abs |
| T1 | 吸込温度 | K |
| n | 吸込温度の計測点数 | — |
| π | 圧力比 | — |

添字 c は換算した値を、添字 p は計画性能曲線又は管理曲線から読んだ値を示す。添字 s はサージ点の値を、添字 s' はプレサージ点の値を示す。添字を 2 つ付けるときは、コンマで区切って並べる。例えば Qc,s は、サージ点の換算空気量を示す。

計測値は、いずれも静定を確かめた後の、同じ時刻の値を用いる。時刻の異なる値を組み合わせて、1 つの計測点としてはならない。

## 3. 換算の細目

換算は、(1) で吸込温度を、(2) で吸込全圧及び圧力比を求めたのち、(3) で回転速度及び空気量を標準吸込状態の値に直す順に行う。計算の途中の値は、成績表には記入せず、計算書として原記録に添える。

### (1) 吸込温度

T1 は、n 点の計測値の平均とする。n は、系列により異なる（注 1）。各点の相互差の限度は、KS-TC-P001 の 3-3 による。

計測の途中で熱電対が断線するなどして、一部の点の値が得られなかった場合は、注 2 による。

平均は摂氏で求め、小数第 2 位まで表す。絶対温度にするときは、273.15 を加える。運転室の扉を開けたまま計測すると、各点の差が大きくなるので、計測のあいだは扉を閉める。吸込口の近くに、暖かい空気を出す機器を置いてはならない。

### (2) 吸込全圧

p1 は、p0 から吸込側の損失を差し引いて求める。吸込側の損失は、型式ごとに、別表 1 の a 欄の値とする。a 欄は、消音器を取り付けた状態の値である。吸込側の流速は小さいので、吸込側の動圧は考えない。

p2 は、吐出管の静圧に動圧を加えて求める。動圧の計算に用いる吐出管の内径は、別表 1 の b 欄の値とする。π は、p2 を p1 で除して求め、換算しない。

p0 は、計測点ごとに読んだ値を用いる。運転の始めに読んだ値を、全部の計測点に用いてはならない。

### (3) 換算回転速度及び換算空気量

Nc 及び Qc は、KS-TC-P001 の 4-2 の方法で求める。Nc は整数に、Qc は小数第 3 位に丸める。丸めは、判定の直前に 1 回だけ行い、途中の値は丸めない。

NE60 系列は、圧力比が高く、吐出空気温度が高くなる。吐出空気温度は換算には用いないが、オリフィス管の位置の空気の密度を求めるのに用いるので、2 点の差が大きい場合は、計測し直す。

顧客の購入仕様書が別の標準状態を指定している場合は、その状態への換算を別に行い、この基準による値と並べて示す。判定は、この基準による値で行う。

## 4. 判定

判定は、(1) から (3) までの順に行い、すべてが許容範囲に入ったとき、性能を合格とする。初号機の 1 台目から 3 台目までは計画性能曲線と、量産機は管理曲線と比べる。どちらの曲線と比べたかは、成績表の備考に記入する。

### (1) サージ誤差

サージ誤差は、次の式で求める。

サージ誤差（%）＝（Qc,s − Qp,s）÷ Qp,s × 100

Qp,s は、計測した π と同じ圧力比における、計画サージングライン上の空気量とする。量産機では、管理曲線のサージングライン上の値を用いる。プレサージ点が記録されている場合の扱いは、注 5 による。

サージ誤差は、小数第 1 位まで求める。許容範囲は、KS-TC-T001 の別表 1 による。範囲の境界に等しい値は、合格とする。符号が正のときは、サージングラインが計画より大風量の側にあることを示す。

### (2) 回転誤差

回転誤差は、次の式で求める。

回転誤差（%）＝（Nc − Np）÷ Np × 100

Np は、計測点の Qc 及び π に対応する、計画性能曲線上の回転速度とする。量産機では、管理曲線の上の値を用いる。Np は、曲線の上で、隣り合う回転速度の線のあいだを比例で読む。回転速度の線が 1 本しか無い管理曲線では、その線からの空気量のずれを回転速度のずれに直して求める。直し方は、管理曲線の余白に示す式による。

回転誤差は、小数第 1 位まで求める。許容範囲は、KS-TC-T001 の 6.1 による。回転誤差は、計測した全部の点について求め、どの点も許容範囲に入っていなければならない。

### (3) 計測点の相互の誤差

相互の誤差は、同じ回転速度で計測した各点の回転誤差のうち、最大の値と最小の値との差とする。許容範囲は、KS-TC-T001 の 6.1 による。

相互の誤差が許容範囲を超えた場合は、計測器の導管の漏れ及び静定の不足を疑い、その回転速度の全点を計測し直す。計測し直しても超える場合は、過技性に連絡する。

2 点だけを計測する型式では、その 2 点の回転誤差の差を、相互の誤差とする。

## 5. 計算例

NA54 の量産機について、チェック回転速度におけるサージ点の例を示す。

- 計測値: N は 14,391 min-1、吸込温度の平均は 20.11 ℃、p0 は 101.91 kPa、Q は 9.711 m3/s、p2 は 351.21 kPa abs
- 吸込全圧: 別表 1 の a 欄から 0.41 kPa を差し引き、p1 は 101.50 kPa
- 圧力比: π は 3.46
- 温度の比の平方根は 1.0097、圧力の比は 0.98424
- 換算: Nc は 14,531 min-1、Qc は 9.651 m3/s

管理曲線から読んだ Qp,s が 9.551 m3/s のとき、サージ誤差は ＋1.0 % となる。同じ計測点で Np が 14,461 min-1 のとき、回転誤差は ＋0.5 % となる。

中間空気量点の回転誤差が ＋0.3 %、大風量点の回転誤差が ＋0.2 % であったとすると、相互の誤差は 0.3 % となる。

NA36 の量産機について、チェック回転速度における大風量点の例を示す。

- 計測値: N は 22,771 min-1、吸込温度の平均は 16.11 ℃、p0 は 101.31 kPa、Q は 3.551 m3/s、p2 は 252.51 kPa abs
- 吸込全圧: 別表 1 の a 欄から 0.31 kPa を差し引き、p1 は 101.00 kPa
- 圧力比: π は 2.50
- 温度の比の平方根は 1.0167、圧力の比は 0.98911
- 換算: Nc は 23,151 min-1、Qc は 3.571 m3/s

管理曲線から読んだ Np が 23,081 min-1 のとき、回転誤差は ＋0.3 % となる。

## 注

（注 1）n は、KS-TC-T001 の別表 1 に示す点数とする。

（注 2）n が 6 の系列に限り、n−1 点で T1 を求めてよい。この場合は、備考に符号 Z-31 を記入する。n が 4 の系列では、認めない。
