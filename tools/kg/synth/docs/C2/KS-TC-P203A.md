# RK10・RM20 系列過給機 コンプレッサ性能換算及び判定基準

| 項目 | 内容 |
|---|---|
| 文書番号 | KS-TC-P203 |
| 改正記号 | A（2019.10.30） |
| 主管部門 | 過給機事業部 技術部 性能開発課（過技性） |
| 配布先 | 過検 2、過運 1、控 1 |

## 1. 適用

この基準は、RK10 系列及び RM20 系列の過給機について、単独試運転で計測したコンプレッサ性能を換算するときの細目、初号機の判定、及び計算例を定める。

換算の共通の方法は、KS-TC-P001 の 4 による。標準吸込状態は、同基準の 4-1 による。この基準は、同基準の 4-4 に定める系列別の細目に当たる。

量産機の判定は、KS-TC-T001 の 6.1 及び KS-TC-T202 による。

この系列は、第 3 運転台で、圧縮空気によりタービンを駆動して運転する。吸込側に消音器を付けず、吸込ベルマウスを用いることを前提として、細目を定めている。運転の条件がこれと異なる場合は、換算の前に過技性に照会する。

計測は過運が行い、換算及び誤差の計算は過検が行う。過技性は、計画性能曲線を発行し、判定に疑義がある場合の技術の審査を受け持つ。計算書は、過検が作り、初号機の記録に添える。量産機では、計算書を作らず、換算した値を成績表に直接記入する。

## 2. 計測値及び記号

この基準で用いる記号は、次による。

| 記号 | 計測値 | 単位 |
|---|---|---|
| N | 回転速度 | min-1 |
| Q | 空気量 | m3/s |
| T1 | 吸込空気温度（2 点の平均） | K |
| P1 | 吸込全圧 | kPa |
| P2 | 吐出全圧 | kPa |
| Nc | 換算回転速度 | min-1 |
| Qc | 換算空気量 | m3/s |
| Nt | 規定チェック回転速度 | min-1 |
| k | 吸込側の損失の係数 | — |
| Pd | ベルマウスののど部の動圧 | kPa |

添字の m は、計画性能曲線から読んだ値を示す。添字の c は、標準吸込状態に換算した値を示す。計画性能曲線は、過技性が型式ごとに発行する。

圧力は、すべて絶対圧力で表す。温度は、換算の計算では絶対温度を用い、成績表には摂氏で記入する。回転速度は、計測点ごとに、ほかの計測値と同じ時刻の値を用いる。記号は、KS-TC-P001 で用いるものと合わせてあり、この基準で加えたものは k 及び Pd である。

## 3. 換算の細目

換算は、KS-TC-P001 の 4-2 及び 4-3 による。この系列では、次の (1) から (4) までを加える。細目は、初号機及び量産機に共通して適用する。細目に当てはまらない計測点があった場合は、その旨を計算書に記し、判定に用いた点と区別する。

### (1) 吸込空気温度

吸込空気温度は、ベルマウスの外周の 2 点の平均とする。平均は、算術平均とする。この系列は計測点が 2 点であるため、2 点の差が 1.2 ℃ を超える場合は、その計測点を換算に用いない。運転室の換気を調整してから、計測し直す。

熱電対は、ベルマウスの入口の面から 100 mm 以内の外周に、向かい合わせに取り付ける。日射又は運転台の放熱を受ける位置を避ける。

### (2) 吸込全圧

吸込ベルマウスを用いる運転では、吸込側の損失を、別表 1 の係数 k に動圧を乗じた値とする。動圧は、空気量とベルマウスののど部の断面積から求める。消音器を付けて運転した場合は、この基準を適用せず、過技性に照会する。

吸込全圧 P1 は、大気圧力から、この損失を差し引いた値とする。大気圧力は、計測点ごとに読んだ値を用い、運転の始めの値で代えてはならない。ベルマウスの入口に金網を付けて運転した場合は、金網の損失を別に見込む必要があるので、過技性に照会する。

### (3) 駆動空気の影響

圧縮空気でタービンを駆動する運転では、タービンから出た冷たい空気が、吸込側へ回り込むことがある。吸込空気温度が大気温度より 2 ℃ 以上低い計測点は、換算に用いない。

回り込みを認めた場合は、タービンの出口に導風の筒を付け、運転室の外へ排気を導いてから、計測し直す。

### (4) 計算のけた数

換算回転速度は整数、換算空気量は小数第 3 位、圧力比は有効数字 3 けたで表す。計算の途中の値のけた数は、KS-TC-P001 の 4-2 による。誤差は、百分率の小数第 2 位まで求める。丸めは、最後の結果に対して 1 回だけ行う。

## 4. 判定

初号機の判定は、計画性能曲線に対する次の誤差による。誤差は、規定チェック回転速度での計測点について求める。

判定は、台ごとに行う。いずれかの誤差が許容値を超えた場合は、その台を不合格とし、過検が過技性に連絡する。過技性は、仕様部品の寸法の記録と計測値を調べ、再計測又は仕様部品の見直しを過検に回答する。

### (1) サージ誤差

サージ誤差は、サージ点の換算空気量 Qc と、計画性能曲線のサージングライン上の空気量 Qm との差を、Qm で除した値とする。サージ誤差は、±4.2 % 以内とする。

プレサージ点を認めた場合も、サージ誤差はサージ点で求める。プレサージ点の空気量は、参考として計算書に併記する。

### (2) 回転誤差

回転誤差は、換算回転速度 Nc と、計測点を計画性能曲線に重ねて読んだ回転速度 Nm との差を、Nm で除した値とする。計算には、機関の作動線に最も近い計測点を用いる。回転誤差は、±2.2 % 以内とする。

機関の作動線は、計画性能曲線に記入されたものを用いる。作動線が記入されていない型式では、中風量点のうち空気量の大きい側の点を用いる。

### (3) 計測点の相互の誤差

同じ回転速度で計測した各点の換算回転速度の差は、0.2 % 以内とする。これを超える場合は、静定が不十分であったものとして、計測し直す。静定の確認は、KS-TC-P001 の 5 による。計測し直しても差が縮まらない場合は、回転速度の検出の側に原因があることが多いので、検出器の取付けを確かめる。

## 5. 計算例

RK16 の 1 台目の、規定チェック回転速度での計測値による例を示す。換算は、3. の細目を当てはめた後の値で行う。計画性能曲線から読む値は、二人が別々に読み、差が無いことを確かめてから用いる。

a. サージ誤差: Qc = 0.852 m3/s、Qm = 0.832 m3/s のとき、（0.852 − 0.832）÷ 0.832 × 100 = 2.40 % となり、合格である。

b. 回転誤差: 中風量点の Nc = 39,872 min-1、計画性能曲線に重ねて読んだ Nm = 40,192 min-1 のとき、（39,872 − 40,192）÷ 40,192 × 100 = −0.80 % となり、合格である。

c. 計測点の相互の誤差: サージ点、中風量点及び大風量点の Nc のうち、最大と最小の差が 40 min-1 のとき、40 ÷ 39,872 × 100 = 0.10 % となり、合格である。

d. 吸込全圧: 大気圧力が 101.2 kPa、のど部の動圧 Pd が 2.50 kPa、係数 k が 0.032 のとき、吸込側の損失は 0.032 × 2.50 = 0.08 kPa であり、P1 = 101.2 − 0.08 = 101.12 kPa となる。

計算の過程は、けた数を落とさずに行い、結果を小数第 2 位に丸める。

この例の値は、計算の手順を示すためのものであり、型式の性能を示すものではない。計算書の書式は定めないが、a から c までの順に記し、用いた計画性能曲線の発行の日を添える。

## 別表 1 型式別の換算の係数

| 型式 | インペラ外径（mm） | のど部の内径（mm） | 係数 k |
|---|---|---|---|
| RK12 | 122 | 92 | 0.032 |
| RK14 | 142 | 102 | 0.032 |
| RK16 | 162 | 122 | 0.032 |
| RK18 | 182 | 132 | 0.042（注 2） |
| RM22 | 222 | 162 | 0.042 |
| RM24 | 252 | 182 | 0.042 |
| RM26 | 282 | 202 | 0.052 |

のど部の内径は、吸込ベルマウスの最も細い部分の内径を示す。動圧 Pd は、空気量を、この内径から求めた断面積で除して流速を求め、計算する。インペラ外径は、計画性能曲線との照合に用いる。インペラを削って外径を変えた仕様では、表の値を用いず、仕様部品の図面の値による。表の係数は、ベルマウスの形が変わらない限り、仕様部品を改めても変えない。

## 注

（注 1）計画性能曲線は、技術資料 TS-0520 の付図として発行する。検査課には、型式ごとに写しを 1 部送る。

（注 2）この型式は、のど部に計測用の継ぎ輪を入れて運転するため、係数を大きくしている。継ぎ輪を外して運転した場合は、ほかの型式と同じ係数を用いる。

（注 3）4. の許容値は、初号機に限る。量産機のサージング点の許容範囲は、KS-TC-T001 の別表 1 による。

（注 4）係数 k は、過技性が模型の試験で求めたものである。ベルマウスを作り替えたときは、過技性が係数を確かめ直す。

（注 5）顧客の購入仕様書が別の標準状態を指定している場合の併記は、KS-TC-P001 の 4-1 による。

（注 6）3. の (3) の回り込みは、冬季に、運転室の扉を閉めて運転したときに起こりやすい。

（注 7）型式を追加したときは、過技性が別表 1 に係数を加える。係数が定まるまでは、その型式の換算を過技性が行う。
