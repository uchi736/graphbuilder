## 1. 適用

この基準は、HX40 系列及び DS70 系列過給機の単独試運転で計測したコンプレッサ性能について、換算の細目、判定の方法及び計算例を定める。KS-TC-P001 の 4-4 を受けて定めるものである。

計測の方法及び換算の共通事項は、KS-TC-P001 による。標準吸込状態は、同基準の 4-1 による。この基準と同基準とで定めが異なる場合は、この基準を優先する。

この基準は、初号機の試験及び量産機の試運転検査の両方に用いる。タービンの性能及び過給機の総合効率は、この基準の対象としない。

換算及び判定の計算は、過検が行う。計算の方法に疑義がある場合は、過技性に照会する。

## 2. 計測値及び記号

換算及び判定に用いる計測値の記号は、次による。

| 記号 | 計測値 | 単位 |
|---|---|---|
| N | 回転速度 | min-1 |
| Q | 空気量 | m3/s |
| T1 | 吸込空気温度（各点の平均） | K |
| P1 | 吸込全圧 | kPa |
| P2 | 吐出全圧 | kPa |
| Tm | 段間の温度（高圧段側の計測座） | K |
| Pm | 段間の全圧（高圧段側の計測座） | kPa |
| π | 圧力比 | — |

DS70 系列では、低圧段の値に添字 L を、高圧段の値に添字 H を付ける。換算した値には、記号の右肩に * を付ける。計測値のけた数は、計測共通の 6 による。

温度は、換算では絶対温度で用いる。圧力は、すべて絶対圧力とする。段間の温度及び全圧は、HX40 系列では用いない。

## 3. 換算の細目

### (1) HX40 系列

換算回転速度及び換算空気量は、KS-TC-P001 の 4-2 により求める。吸込空気温度 T1 は、KS-TC-T001 の別表 1 に示す点数の計測値を平均して用いる。各点の相互差が計測共通の 3-3 の値を超えた計測点は、換算に用いない。

消音器を取り付けて計測した場合は、吸込全圧 P1 を、大気圧力から別表 1 の吸込損失を差し引いて求める。吸込ベルマウスを用いた場合は、吸込損失を 0 とする。

### (2) DS70 系列の低圧段

低圧段の換算は、前号と同じとする。ただし、低圧段の吐出全圧には、段間ダクトの低圧段側の計測座で求めた全圧を用いる。

計測座の全圧は、そこで計測した静圧に、空気量から求めた動圧を加えて求める。動圧の計算には、計測座の位置の内径を用いる。

段間ダクトの計測座は、低圧段側及び高圧段側の 2 箇所にある。低圧段側の全圧が高圧段側の全圧より低い場合は、導管の詰まり及び漏れを確かめる。

### (3) DS70 系列の高圧段

高圧段は、段間の状態を吸込状態とみなして換算する。吸込温度には段間の温度 Tm を、吸込全圧には段間の全圧 Pm を用いる。いずれも、段間ダクトの高圧段側の計測座の値とする。

高圧段の性能は、標準吸込状態ではなく、次の段間基準状態に換算して表す。

- 段間基準温度: 323 K
- 段間基準全圧: 243 kPa

段間の計測値が得られなかった計測点は、換算しない。この場合の扱いは、注 2 による。

### (4) 総合圧力比

DS70 系列の総合圧力比は、高圧段の吐出全圧と低圧段の吸込全圧との比とする。低圧段の圧力比と高圧段の圧力比との積は、段間ダクトの損失の分だけ、総合圧力比より大きくなる。両者の差が 1.3 % を超える場合は、段間の計測を確かめる。損失の目安は、注 6 に kPa で示す。

総合圧力比は、判定には用いない。顧客へ提出する性能曲線に、参考の値として記入する。

### (5) 丸め

換算回転速度は、10 min-1 の位に丸める。換算空気量及び圧力比のけた数は、計測値と同じとする。誤差は、百分率の小数第 1 位まで求める。計算の途中では、丸めない。

丸めは、四捨五入による。許容値との比較は、丸めた後の値で行う。丸めた値が許容値にちょうど等しい場合は、許容値に入るものとする。

## 4. 判定

判定は、換算した値を、KS-TC-P304 により管理する性能管理曲線と比べて行う。初号機の 1 台目から 3 台目までは、過技性が示す計画性能曲線と比べる。

DS70 系列は、低圧段及び高圧段のそれぞれについて、次の誤差を求める。誤差の符号は、管理曲線より空気量又は回転速度が大きい側を正とする。

### (1) サージ誤差

サージ誤差は、サージ点の換算空気量と、同じ圧力比における管理曲線のサージラインの空気量との差を、サージラインの空気量に対する百分率で表したものとする。

許容値は、KS-TC-T001 の別表 1 による。ただし、DS70 系列の高圧段は、段間の計測の不確かさを見込み、±4.3 % とする。

サージ誤差が許容値を外れた場合は、性能に係る不適合（区分 乙）として、QK-TC-02 の第 7 条により処置を決定する。

### (2) 回転誤差

回転誤差は、計測点の換算回転速度と、同じ空気量及び圧力比を通る管理曲線の回転速度との差を、管理曲線の回転速度に対する百分率で表したものとする。

許容値は、KS-TC-T001 の 6.1 による。ただし、DS70 系列の高圧段は、±2.3 % とする。許容値を外れた場合の処置は、前号と同じとする。

DS70 系列の高圧段は、回転速度を合わせ込まずに計測するので、計測点が管理曲線の回転速度一定の曲線から離れることがある。この場合は、上下の 2 本の曲線のあいだを、空気量に比例させて補間する。

### (3) 計測点の相互の誤差

規定チェック回転域で計測した各点について、回転誤差を求め、最も大きい値と最も小さい値との差を、相互の誤差とする。許容値は、KS-TC-T001 の 6.1 による。

相互の誤差だけが許容値を外れた場合は、計測の誤りを疑い、不適合とする前に、静定を確かめて計測をやり直す。やり直しても外れる場合は、(1) の処置による。

2 点だけを計測する型式では、2 点の回転誤差の差を、相互の誤差とする。

## 5. 計算例

HX44 を、消音器を取り付けて運転し、規定チェック回転域のサージ点を計測した例を示す。標準吸込状態の温度 Ts 及び全圧 Ps は、KS-TC-P001 の 4-1 による。

- 計測値: N = 36,380 min-1、T1 = 303.0 K、大気圧力 100.63 kPa、P2 = 433.3 kPa、Q = 3.133 m3/s
- 吸込全圧: P1 = 100.63 − 0.33 = 100.30 kPa
- 温度の比の平方根: √(Ts/T1) = 0.9934
- 全圧の比: Ps/P1 = 0.9960
- 換算回転速度: N* = 36,380 × 0.9934 = 36,140 min-1
- 換算空気量: Q* = 3.133 × 0.9934 × 0.9960 = 3.100 m3/s
- 圧力比: π = 433.3 / 100.30 = 4.32

管理曲線のサージラインの空気量が、圧力比 4.32 で 3.053 m3/s のとき、サージ誤差は (3.100 − 3.053) / 3.053 = +1.5 % となり、許容値に入る。

同じ点を通る管理曲線の回転速度が 36,410 min-1 のとき、回転誤差は (36,140 − 36,410) / 36,410 = −0.7 % となり、許容値に入る。

DS74 の高圧段の例を示す。段間の計測値が Tm = 333.0 K、Pm = 253.3 kPa、高圧段の回転速度が 39,100 min-1 のとき、温度の比の平方根は √(323 / 333.0) = 0.9849、換算回転速度は 39,100 × 0.9849 = 38,510 min-1 となる。換算空気量は、高圧段の吸込みの体積流量に、同じ平方根と、全圧の比 243 / 253.3 = 0.9593 とを乗じて求める。

## 注

（注 1）別表 1 の値は、規定チェック回転域におけるものである。他の回転域でも、同じ値を用いる。

（注 2）3. の (3) の末尾に当たる点は、判定に用いない。曲線には、白抜きの記号で記入する。同じ回転域で 2 点を超える場合は、その回転域をやり直す。

（注 3）3. の (3) の基準の状態は、設計点における値である。A 改正で見直したので、それより前の曲線と比べるときは、過技性に換算を依頼する。

（注 4）計算は、過技性が配布する計算書の書式による。書式を変えて用いてはならない。書式の版は、計算書の右上に記してある。

（注 5）1. の後段を適用するのは、3. の (3) 並びに 4. の (1) 及び (2) のただし書の 3 箇所である。過検は、これらを KS-TC-P001 の次の改正で同基準に注記する。

（注 6）3. の (4) の目安とする値は、DK-310 では 0.233、DK-320 では 0.333、DK-330 では 0.433 とする。
