# 圧力計測器 校正要領

| 項目 | 内容 |
|---|---|
| 文書番号 | KS-TC-C502 |
| 改正記号 | B（2018.06.10） |
| 主管部門 | 生産技術部 計測管理室（計管） |
| 配布先 | 過検 1、過運 1、過品管 1、控 1 |

## 1 適用

この要領は、過給機の単独試運転に用いる圧力計測器のうち、差圧伝送器 DP-10、圧力伝送器 PT-20 及び気圧計 BR-80 について、校正の手順及び合否の判定を定める。

校正の計画、記録、表示及び保管は、KS-TC-C501 による。この要領は、同基準の 5 項を、圧力計測器について具体に定めたものである。

潤滑油供給ユニット及び運転台の盤に付いた圧力計は、この要領の対象としない。

## 2 関連基準

- KS-TC-C501 計測器 校正管理基準
- KS-TC-P001 過給機 計測及び性能換算 共通基準
- KS-TC-T001 過給機 単独試運転 共通基準
- KS-TC-L001 過給機 試運転用潤滑油及び冷却水 供給条件基準

関連基準は、いずれも最新版を用いる。

## 3 標準器及び器具

校正には、重錘形圧力標準器 ST-210 を用いる。ST-210 の範囲及び精度は、KS-TC-C501 の別表 2 による。

(1) 圧力の媒体は、乾燥した窒素とする。
(2) 重錘は、素手で触れてはならない。手袋を着け、刻印の番号の順に載せる。
(3) ピストンは、重錘を載せたのち、手で回して浮かせ、回転が止まる前に読む。
(4) 標準器と計測器の受圧部との高さの差は、50 mm 以内とする。
(5) 重錘及びピストンは、校正の前に、糸くずの出ない布でふく。
(6) ST-210 は、用いる前に、付属の水準器で水平を確かめる。

接続の管及び継手は、校正の前に漏れを確かめる。漏れは、校正の範囲の上限の圧力を加えて元弁を閉じ、60 秒間の降下で調べる。降下が認められる場合は、継手を締め直し、もう一度調べる。

## 4 共通の手順

### 4-1 準備

(1) 計測器を校正室に置き、KS-TC-C501 の 5-2 項に定める時間、室温になじませる。
(2) 外観を調べ、受圧部の傷、導圧口のつぶれ及び封印の破れが無いことを確かめる。
(3) 電源を入れ、5 の各項に示す時間、通電する。
(4) 圧力を加えない状態で、出力のゼロ点を読む。この値は、調整せずに記録する。

封印が破れている計測器は、校正を始める前に、計測管理室長に報告する。この場合は、臨時の校正として扱う。

### 4-2 加圧及び読取り

加圧の段階、順及び保持は、別表 1 の符号による。計測器ごとの符号は、5 の各項に示す。

(1) 圧力は、下の段階から順に加える。行き過ぎた場合は、いったん下の段階まで戻してから、加え直す。
(2) 各段階で、別表 1 の保持のあいだ待ち、出力を 3 回読んで平均する。
(3) 往復と示す符号では、上限に達したのち、同じ段階を逆の順にたどる。

読みは、計測器の出力を、試運転のときと同じ収録装置の入力につないで採る。指示計だけを読んで校正してはならない。つないだ入力の番号は、記録票に記入する。

### 4-3 器差の計算

器差は、段階ごとに、計測器の読みから標準器の値を引いて求める。往復の校正では、行きと戻りとを別に求め、大きい方を採る。

標準器の値には、値付けの証明書に示された補正を加える。重力の加速度による補正は、証明書の値に含まれているので、あらためて行わない。器差は、5 の各項の許容差と同じけた数まで求め、その下のけたは切り捨てない。

### 4-4 校正の中断

加圧の途中で、圧力の降下、出力の乱れ又は校正室の室温の外れを認めたときは、校正を中断し、圧力を抜く。原因を除いたのち、4-1 の (4) からやり直す。

中断の前に採った読みは、用いない。中断の理由及び時刻は、記録票の備考に記入する。

## 5 計測器別の要領

### 5-1 DP-10

| 項目 | 内容 |
|---|---|
| 校正の範囲 | 0 kPa から 25 kPa まで |
| 加圧の符号 | 別表 1 の符号 C |
| 通電 | 加圧の前に 45 分以上 |
| 許容差 | ±0.125 kPa |
| 封印 | ゼロ点及びスパンの調整ねじ |

差圧伝送器は、高圧側の導圧口に圧力を加え、低圧側は大気に開放する。均圧弁は、校正のあいだ閉じておく。受圧部は水平に置き、導圧口に残った水を抜いてから加圧する。

### 5-2 PT-20

| 項目 | 内容 |
|---|---|
| 校正の範囲 | 0 kPa から 705 kPa まで |
| 加圧の符号 | 別表 1 の符号 A |
| 通電 | 加圧の前に 35 分以上 |
| 許容差 | ±1.75 kPa |
| 封印 | ゼロ点及びスパンの調整ねじ |

圧力伝送器のうち、絶対圧の出力をもつものは、校正のときの大気圧力を BR-80 で読み、標準器の値に加える。ゲージ圧の出力をもつものは、加えない。出力の区別は、銘板で確かめる。

### 5-3 BR-80

| 項目 | 内容 |
|---|---|
| 校正の範囲 | 945 hPa から 1,045 hPa まで |
| 加圧の符号 | 適用しない |
| 通電 | 不要 |
| 許容差 | ±0.45 hPa |
| 封印 | 補正ねじ |

気圧計は、据え付けた場所から外さず、現場で校正する。ST-210 で値付けした携帯の基準器を運び、同じ高さに並べて、読みを比べる。基準器の運び方及び据えてからの扱いは、注 3 による。

校正点は、その日の大気圧力の 1 点とし、日を変えて 3 回行う。BR-80 は、DP-10 及び PT-20 と等級が異なる。等級及び周期は、KS-TC-C501 の 4-1 項による。

## 6 合否及び処置

### 6-1 合否

すべての段階で、器差が 5 の各項の許容差以内であれば、合格とする。1 つの段階でも許容差を超えた場合は、校正外れとし、調整の前の器差を記録票に記入する。

ゼロ点だけが外れている場合も、校正外れとする。ゼロ点を合わせ直しただけで、合格としてはならない。

### 6-2 調整

校正外れの計測器は、前項の記入を済ませたのち、調整ねじで調整し、4-2 の手順を初めからやり直す。調整は 2 回までとし、それでも合格しない場合は、修理に出す。

調整の後の校正に合格した場合も、調整の前の校正外れについて、KS-TC-C501 の 6-1 項の通知を行う。調整の後は、調整ねじに新しい封印をする。

### 6-3 記録

校正の結果は、校正記録票に記入する。記録票には、KS-TC-C501 の 5-4 項に掲げる事項のほか、加圧の符号、媒体、校正室の気圧及び段階ごとの読みを記入する。

往復の校正では、行きと戻りの読みを別の欄に記入する。平均する前の 3 回の読みは、記録票の裏面に残す。欄を取り違えたときは、「検査記録及び帳票管理規定」の、訂正の定めによる。

## 7 使用中の点検

試運転の前に、過運は、圧力を加えない状態で DP-10 及び PT-20 の出力を読み、ゼロ点のずれを確かめる。導圧管に水がたまっているとゼロ点がずれるので、ずれを認めたときは、まず導圧管の水を抜き、もう一度読む。

水を抜いてもずれが残る場合は、使用せず、計管に届け出る。この場合は、KS-TC-C501 の 4-3 項の (4) に当たるものとして扱う。

潤滑油供給ユニットの圧力計との指示の差について、KS-TC-L001 の 8. による連絡を受けた場合、計管は、PT-20 を予備の器械と取り替え、取り外したものを臨時の校正にかける。

## 8 予備の器械

DP-10 及び PT-20 は、同じ管理番号で予備の器械を 1 台ずつ持つ。予備の器械は製造番号で区別し、使わなかった場合も、同じ周期で 1 台ずつ校正する。

校正のために計測棟へ戻すあいだは、予備の器械を貸し出す。予備の器械の封印及びラベルは、KS-TC-C501 の 5-5 項による。BR-80 には、予備を置かない。

## 9 安全

(1) 窒素の容器は、鎖で固定し、調整器の出口の圧力を、校正の範囲の上限の 1.5 倍以下に合わせる。
(2) 加圧のあいだは、保護めがねを着ける。継手のゆるみを、加圧したまま締め直してはならない。
(3) 重錘を載せ、又は降ろすときは、圧力を抜いてから行う。
(4) 校正を終えたときは、元弁を閉じ、管の中の圧力を抜く。
(5) 窒素を多く放出したときは、校正室の換気扇を回す。

## 別表 1 符号別の区分

| 符号 | 段階 | 順 | 保持 |
|---|---|---|---|
| A | 上限の 0、25、50、75、100 % | 往復 | 35 秒 |
| B | 上限の 0、50、100 % | 片道 | 35 秒 |
| C | 上限の 0、20、40、60、80、100 % | 往復 | 135 秒 |
| D | 上限の 0 から 100 % まで 10 % ごと | 往復 | 65 秒 |

符号 B は、封印の破れだけを理由とする臨時の校正に用いる。符号 D は、新たに購入した計測器の最初の校正に用いる。

## 注

（注 1）段階の圧力は、重錘の組合せで作る。組合せの表は、ST-210 の箱のふたの裏に貼ってある。

（注 2）絶対圧とゲージ圧との区別を誤ると、器差が大気圧力の分だけずれる。銘板が読めないものは、圧力を加えない状態の出力で見分ける。

（注 3）基準器は、専用の箱に入れ、手で提げて運ぶ。台車に載せてはならない。据えてから 105 分のあいだは、読みを採らない。
